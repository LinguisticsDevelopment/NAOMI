# LanguageCommons
This is for the Structures that both the Server and the Client use

Meaning -> Ideas -> Thoughts

Forms of Thoughts:
Inclusion = "and" - "but" is this but negation-bool tagged
Exclusion = "or"
Change = verbs
State = "is/be"
Condition = "if"
Concept = single word that is not a verb
Connection = prepositions 

Inclusion:
    -Components []*Thought
Exclusion:
    -Alternatives []*Thought
Change: 
    =Concept = Relevant Verb
    -Subject *Thought
    -Object *Thought
    -Indirect *Thought
STATE:
    -Subject *Thought
    -Complement *Thought
Condition:
    -Parameter *Thought
    -If *Thought
    -Else *Thought
Concept:
    =Concept = Relevant Non-Verb
    -Multipliers []*Thought
    -Additives []*Thought
Connection:
    =Concept = Connecting preposition
    -Affected *Thought
    -Related *Thought
