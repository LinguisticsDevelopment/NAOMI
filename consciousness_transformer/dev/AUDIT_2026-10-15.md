## A. Is the headline number real?

**What holds up:**
- **No leakage.** `make_holdout.py:48` draws the test and dev sets (98 each) from the v2 gold, seed 0. Training excludes the held-out sentences by exact text match (`encoder_train_util.py:113-117`). I checked all 10,225 records of `encoder_gold_v4b_16k.jsonl`:
  - 0 records contain a holdout sentence or are contained in one.
  - 0 records have word-Jaccard ≥0.8 with a holdout sentence.
- **Dev and test are separate.** Keep-best uses the dev file; the score is on the test file. Dev uses greedy k=1 decoding (`encoder_train_util.py:256`) while test uses beam 6 rank-1. That is a minor mismatch, not a leak.
- **Rank-1 is genuinely the committed tree.** `rank1 = [forest[0]]` (`encoder_train_util.py:224`), and the forest is sorted by logprob (`encoder_model.py:1101`). It is no longer an oracle.
- **Modifiers are counted.** Edges are every `clause["roles"]` entry (`encoder_model.py:303-305`). DESCRIPTION is the most frequent role in the 16K gold (6,035 vs 5,801 SUBJECT).

**What weakens it:**
1. **No cheat baseline, which breaks CLAUDE.md's law.** I wrote a ~30-line POS heuristic (scorer reproduced from `score_record`, not run against the code):
   - Predicate: first VERB, else AUX.
   - Subject: last nominal before it. Object: first nominal after it.
   - DESCRIPTION: every ADJ/DET/ADV/NUM. PLACE: the nominal after an ADP.
   - Gtype: taken from whether the token has candidates.

   On the same 98 holdout sentences it scores **edge-F1 0.40** (P 0.37, R 0.42). So the learned encoder's real margin is about +0.22, not 0.62 above zero.
2. **Edge-F1 is lenient by construction:**
   - An edge is `(relation, token_index, gtype)`. The sense is never chosen or scored (`encoder_model.py:928-932`).
   - Gtype is largely given by the input: a token with candidates gets "sense".
   - Edges are pooled across clauses (`_tree_edge_set`, `:1230-1238`), so putting a node in the wrong clause costs nothing. Only struct-exact (0.214) sees clause structure.
3. **The gold is a partial skeleton.** Across the 16K gold, only **46%** of tagger-VERB tokens appear anywhere in the gold tree. **39%** of records cover fewer than half their verbs.

   Example from the 16K gold: "Either the well was very deep, or she fell very slowly, for she had plenty of time…" becomes a single clause with predicate `was`, `she` labelled FOR and `the` labelled DESCRIPTION. Every other clause is gone.

   The encoder is being trained to reproduce these drops. For comprehension, a dropped clause is a fact that is never written to memory.
4. **One seed.**
   - The scaling-curve points at 3,000/8,000 and the 10,225 checkpoint are seed 0 only.
   - The only seed pair (v4b_margin) differs by 0.026.
   - With n=98 the 95% interval is roughly ±0.05.
   - That supports "it scales" (0.49→0.55→0.63). It does **not** support the 0.632-vs-0.622 or 0.632-vs-0.579 (USVS soft-loss) distinctions as more than about 2σ single-seed calls.

## B. Is the direction sound?

On teacher-parseable text the encoder is distillation at 0.62 against a teacher that is itself partial. Its claimed value lies elsewhere:
- **(i) The teacher's complement.** Measured once (2026-09-08) at 18.2% usable, on the old checkpoint, with a judge the director called lenient. **Never re-measured on the 0.622 checkpoint.**
- **(ii) Code-switching.** No evidence at all. `N_RULES` is still 7 hard-coded POS heuristics (`encoder_model.py:91-100`, `compute_fired_rules :147-205`). `PRIMES = [YOU, I, <UNK_PRIME>]` (`:84`). The lead's 09-08 decision to keep the learned encoder as the default rests on Spanglish (ledger L1232), which is a capability that does not exist.

Nothing since 09-08 shows the encoder beating the teacher anywhere that matters. The obvious engineering answer for comprehension is:
- use the teacher where it parses (FairytaleQA "usable" 58.8%);
- use the encoder only on the complement;
- measure what each contributes downstream.

The lead rejected the hybrid. That is his call, but it was decided **before** any downstream number existed.

**"Encoder first, then comprehension" is the wrong order.** Previous-audit finding 8 (can the GRU resolver resolve a candidate lattice / answer from memory on real prose?) is still completely untouched. The lead's 09-08 reframe ("evaluate the existing resolver on encoder lattices once the encoder exists") was never dispatched. Every further encoder point (v5 gold, 16K+) improves a component whose usefulness downstream is unknown.

## C. Can the K-12 plan run without a decoder?

In principle yes, as MC selection. In practice the planned benchmark is broken.

`convert_fairytaleqa.py:491-532` draws distractors from **other stories' answers of the same attribute**. The "entity" type means the answer is verbatim in the passage. I ran the cheat "pick the option that appears as a substring of the passage" on the committed 584 MC episodes: it gets **553 unique-correct, 31 ties, 0 misses, so about 97% accuracy.** `eval_prose.py` reports only random and majority floors (`:122-157`).

To make the benchmark usable:
- regenerate distractors as other same-type spans **from the same passage**;
- add a question-word-overlap cheat baseline.

**MCTest's in-story distractors are the better first benchmark.** Only a sample is fetched (`data/k12_samples/mctest`); the sandbox egress was blocked.

With those fixes there are about 2-4 weeks of decoder-free work: entity MC, MCTest, and "not stated" abstention via swapped-passage questions. Beyond that, 80% of FairytaleQA needs realization, and the memory-frame decoder is still the failed design. `DECODER_MEMORY_DESIGN.md` was never revised: no HOLD marker, and the Build order is unchanged at `:76-84`.

   - **Gate:** the encoder (or hybrid) raises answerable-episode coverage by ≥10 pts with no accuracy loss on the shared subset. Otherwise freeze the encoder and use the teacher.

4. **Gold-coverage audit (≈3h).**
   - Hand- or LLM-judge 50 holdout gold trees for dropped clauses and wrong roles.
   - **Gate:** if >30% of records drop a content clause, edge-F1-vs-teacher stops being the encoder's target metric. Measure clause recall against tagger verbs instead, and fix extraction before any more gold.
5. **Abstention probe (≈1 day).**
   - Pair questions with the wrong story's passage; the label is "not stated".
   - **Gate:** abstain-rate ≥70% on mismatched items and ≤15% on matched ones. This is the anti-confabulation claim, measured directly.

A 2-seed rerun of the 10,225 checkpoint is worth doing only if #3 makes the encoder matter.
