# naomi_scaffold

Hand-pattern reader passes and the rule-based answerer (`recall.py`) built on 2026-11-14 and removed the same day by owner decision: hand-written language patterns and a hand-written answerer are antithetical to the design (answering is learned by the consciousness; language rules live only in grammar files). The `runs/naomi_bench_*` numbers came from this code and are a signpost only, not a system result. Do not build on this.
